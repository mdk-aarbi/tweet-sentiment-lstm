The data

TweetEval sentiment is a public benchmark of English tweets labelled positive, negative or neutral. I did not collect it myself. I used the official splits and kept the test set untouched until the final evaluation.

Test set class balance

Neutral 48.3% · Negative 32.3% · Positive 19.3%. Always guessing "neutral" already scores 48.33%, so any model has to beat that to be useful.

Two models, same data

Model A · from scratch

BiLSTM, random embeddings

Embedding (20,000 words, 100 dimensions, learned from zero), bidirectional LSTM with 64 units, dropout 0.5, softmax over 3 classes. Early stopping on validation loss.

Model B · pretrained vectors

BiLSTM, frozen GloVe Twitter

The same network, but the embedding layer is initialised from GloVe Twitter 100d and frozen. 87.9% of the vocabulary has a pretrained vector.

Where the model gets it wrong

Model B made 4,456 mistakes on the test set. 44% of them were truly neutral tweets labelled positive or negative, and 49% were positive or negative tweets predicted as neutral. The sampled examples show why: headlines and questions carrying charged topic words, and feelings that are implied rather than stated. The model reads words, not context, so it has no real handle on sarcasm, news framing or who a feeling is aimed at.

Frozen GloVe vectors changed accuracy by +2.7 points and macro-F1 by +0.032 compared with random embeddings. This comes from a single seeded run, so differences of a point or less should not be over-read.
